# Twilio carries the call, Cursor speaks

The phone call and the SMS share Twilio, ElevenLabs only supplies the voice, and the Cursor cloud agent is the brain that talks and then changes the server. A second model in the voice layer would promise fixes the Cloud Agent will not carry out, and ElevenLabs-native calling would split the phone from the SMS. The Cloud Agent's own harness is already the one we trust, so the voice path adds no prompt stack of its own.
